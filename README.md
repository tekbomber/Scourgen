# SCOURGEN: AFTER HOURS

An endless arcade survival raycaster. MartCo #004, Malevorn, Ohio. Clock in, survive the night shift, and don't let the Scourgen get you.

## Play

Open `index.html` in a browser, or play it live once GitHub Pages is enabled for this repo (Settings → Pages → deploy from the `main` branch, then visit `https://tekbomber.github.io/Scourgen/`).

## Controls

- **WASD** — move
- **Mouse** — look
- **Click** — fire
- **Right-click** — aim
- **R** — reload
- **E** — use
- **ESC** — pause
- Touch controls on mobile.

## Survivors

- **Colt** — Marksman. Precise, tougher, rifle only.
- **Justine** — Scrapper. Faster, hits hard up close, bayonet. Unlock her by reaching Round 6 (3 AM).
